## Title
TriageGenie — Jira triage that runs itself | Codegeist 2026

## Description
Every new Jira issue gets classified, prioritised and answered in seconds —
automatically, and with every decision explained.

TriageGenie is a Forge app for Jira built for Atlassian Codegeist 2026. A
trigger triages each new issue the moment it is created (labels, priority,
first-response comment); the issue panel shows the full score breakdown,
suggested labels, assignee, draft reply and fix plan; one click on Apply
writes it all to the issue. The same four actions are also a Rovo agent and
an MCP server.
